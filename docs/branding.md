# Branding

Kraftverk’s mark is an original geometric emblem: a turbine / optimization-loop “K” energy — not a cliché lightning bolt or RGB gamer motif.

## Assets

| File | Use |
|------|-----|
| `assets/logo.svg` | Canonical full logo (dark field) |
| `assets/logo-dark.svg` | Darker variant |
| `assets/mark.svg` | App mark / avatar |
| `assets/wordmark.svg` | Mark + wordmark |
| `assets/favicon.svg` | Favicon |
| `assets/icon-*.svg` | Icon sizes (SVG masters) |

## Color

- Field: `#101418`
- Accent: `#3d9a8b` → `#2a6f8a`
- Foreground: `#e8eef4`
- Muted: `#8b9aab`

## Tone

Serious performance engineering instrument. Precise, restrained, technical. No neon boost stickers.

## AMD focus (no impersonation)

Kraftverk specializes in AMD systems as an independent open-source project. Do **not**:

- Use AMD corporate logos or wordmarks without a license
- Imply endorsement, partnership, or official AMD affiliation
- Ship “AMD Official” style badges

Preferred framing: “open-source adaptive performance laboratory for AMD systems.”

Trademark notice: AMD is a trademark of Advanced Micro Devices, Inc.

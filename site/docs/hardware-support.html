Hardware Support

Kraftverk is an AMD-exclusive performance platform (policy amd-only-v1). This is a hard gate.

Supported

  • Architecture: x86 / x86_64
  • CPU: AMD (AuthenticAMD)
  • GPU: AMD-only when present (PCI 0x1002); no GPU is allowed

Blocked (exit codes)

  • 20 unsupported architecture
  • 21 Intel CPU
  • 22 NVIDIA GPU
  • 23 Intel GPU
  • 24 unknown CPU vendor
  • 25 unsupported combination

Full details: docs/hardware-support.md

Kraftverk

Evidence-driven systems performance platform

Measure real work. Experiment with reversible settings. Keep only what statistically improves. No magic buttons.

No magic buttons

Kraftverk is a performance engineering system, not another PC “optimizer.” Every kept change is measured, validated, explainable, and restorable.

The loop

  1. Measure
  2. Experiment
  3. Benchmark
  4. Validate
  5. Compare
  6. Keep or Revert
  7. Learn
  8. Repeat

Get started

cargo install --path crates/kraftverk-cli
kraftverk inspect
kraftverk baseline
kraftverk optimize --mode safe --goal balanced
kraftverk report --format html

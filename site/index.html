Kraftverk

Evidence-driven systems performance platform

Measure real work. Experiment with reversible settings. Keep only what statistically improves. No magic buttons.

Download Docs GitHub

Name

Kraftverk is inspired by Swedish — kraftverk means power plant / powerhouse / power station. It is a product name only. Not affiliated with the Kingdom of Sweden or any Swedish government entity.

No magic buttons

Kraftverk is a performance engineering system, not another PC “optimizer.” Every kept change is measured, validated, explainable, and restorable.

The evidence loop

Measure → Experiment → Validate → Improve, then learn and repeat.

  1. Measure
  2. Experiment
  3. Benchmark
  4. Validate
  5. Compare
  6. Keep or Revert
  7. Learn
  8. Repeat

AMD hardware only

Policy amd-only-v1 is a hard gate: x86/x86_64 + AMD CPU; GPU optional but must be AMD if present. NVIDIA/Intel GPU configurations are rejected (exit codes 20–25).

Independent product — not affiliated with or endorsed by Advanced Micro Devices, Inc. AMD is a trademark of Advanced Micro Devices, Inc. No AMD logos are used here.

Get started

cargo build --release -p kraftverk-cli
kraftverk inspect
kraftverk baseline
kraftverk optimize --mode safe --goal balanced
kraftverk report --format html
